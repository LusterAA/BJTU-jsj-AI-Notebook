# BJTU-jsj-AI-Notebook

👨‍🎓 本项目用于分享北京交通大学计算机科学与技术学院人工智能专业本科阶段的课程资料、学习笔记、期末复习资料、课程作业参考、实验报告模板以及学习经验。

本仓库为非营利、永久免费的学习资源共享项目，同学们可以自由查阅和交流。

所有涉及北京交通大学试卷及课件等资料的部分，版权归属于北京交通大学课程组及教师。其他同学提供的资料及解答，版权归属于他们本人，我在这里表示感谢。

本笔记的撰写目的是用作参考，请勿直接抄袭，否则后果自负。

我希望这份资料可以给学弟学妹的学习一点帮助，如果这些资料对你有帮助，欢迎点一个 Star ⭐
